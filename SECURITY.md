# Security

Found a security problem? Please report it in private: [open a GitHub security advisory](https://github.com/IFAKA/zaragoza-free-map/security/advisories/new). Please do not open a public issue for it.

In scope: this app (the code in this repository and the site built from it): script injection, bad headers, leaks of data about the user, a weak service worker or cache.

Out of scope: problems in the services we link to or read (zaragoza.es, CityBikes, Esri, OpenStreetMap, Renfe, Google), and wrong or old data (open a normal issue for that).

This is a small independent project. We answer as soon as we can and thank you in the fix.
